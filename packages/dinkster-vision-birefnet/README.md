# dinkster-vision-birefnet

`dinkster-vision-birefnet` is the separately installable BiRefNet execution
provider for `dinkster.image.matte`. It runs in an isolated pack worker, uses the
digest-pinned general-use BiRefNet checkpoint declared in `dinkster-pack.toml`,
and produces one soft foreground matte per image on CPU.

The checkpoint is read only through `dinkster_api.v1.declared_asset`; execution
never downloads it. Dinkster preflight presents the exact artifact need and
acquires it only with user consent. The pinned 444,473,596-byte artifact has
SHA-256 `9ab37426bf4de0567af6b5d21b16151357149139362e6e8992021b8ce356a154`.
It is the MIT-licensed BiRefNet model repackaged by Comfy-Org at the immutable
revision recorded beside it in `dinkster-pack.toml`.

Each input frame is resized to 1024x1024 with bicubic antialiased resampling,
rounded to the same 8-bit value grid as ComfyUI, and evaluated independently.
The logit mask is resized back to the source dimensions with bicubic sampling
before sigmoid conversion to a float32 foreground matte.

Architecture, preprocessing, and output conversion match ComfyUI commit
`c67885b14556cf3e4e061862925282d403d09862`. The parity vector in
`tests/goldens/birefnet_c67885b.json` is generated by
`tools/gen_birefnet_golden.py`, which refuses a modified reference checkout or
a reference HEAD other than that commit.
