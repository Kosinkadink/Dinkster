# dinkster-vision-hed

`dinkster-vision-hed` is the separately installable native execution provider for
learned ControlNet line and edge preprocessors. It runs in an isolated pack
worker on CPU or CUDA and keeps loaded models in its pressure-governed cache.
AnyLine parks reusable anime weights in host memory while MTEED runs and
releases MTEED before running the selected line-art stage.
M-LSD retries on CPU if CUDA allocation fails instead of returning the pinned
wrapper's silent all-black OOM result.

The provider implements realistic and coarse realistic line art, anime line
art, manga line art, AnyLine's four merge modes, HED soft edges, HED fake
scribbles, TEED, and M-LSD. Checkpoint-free Canny, PyraCanny, standard line art,
threshold scribble, and XDoG execution remains in `dinkster-nodes-image`.

PiDiNet and Scribble PiDiNet workflows fail closed because their bundled model
license requires separate commercial permission. Diffusion Edge workflows also
fail closed because its three-checkpoint, runtime-installed dependency path is
not implemented. This package does not claim support for the rest of
`comfyui_controlnet_aux`.

Model files are read only through `dinkster_api.v1.declared_asset`; execution
never downloads them. Dinkster preflight presents the declared artifact needs and
acquires them only with user consent. Exact digests, byte sizes, and immutable
source URLs are recorded in `dinkster-pack.toml`.

The implemented architectures, resizing, postprocessing, and compatibility
translations match `comfyui_controlnet_aux` commit
`59b1fc411ede8623b2997855b8018f0b3b6cf49f`. The parity vector in
`tests/goldens/line_edge_controlnet_aux_59b1fc4.json` is generated by
`tools/gen_line_edge_goldens.py`, which refuses modified or unpinned reference
and ComfyUI checkouts and verifies every source artifact. Generation uses
Python 3.12 with NumPy 2.5.1, OpenCV 5.0.0.93, and torch 2.13.0.

TEED's declared weights are CC-BY-NC-SA-4.0. AnyLine's MTEED weights use the
OpenRAIL++ license. `WEIGHT_LICENSES.md` links their pinned model cards and
terms. The other model and source licenses are identified in the manifest and
the license files included in the wheel.
