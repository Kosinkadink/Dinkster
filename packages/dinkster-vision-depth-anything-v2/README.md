# dinkster-vision-depth-anything-v2

`dinkster-vision-depth-anything-v2` is the separately installable Depth Anything
V2 Large execution provider for `dinkster.preprocess.model_depth`. It runs in an
isolated CPU worker and emits normalized relative-depth control hints.

The provider reads its model only through `dinkster_api.v1.declared_asset` and
never downloads during execution. Dinkster preflight presents the exact artifact
need and acquires it only with user consent. The immutable model artifact is
1,341,322,868 bytes with SHA-256
`4e01e34ed5549b529b70b92d53226bc370f03041977b390d3dde45d47f516cf9`.
Its Hugging Face revision and BLAKE3 identity are pinned in `dinkster-pack.toml`.

The weights may not be used for commercial purposes. The model implementation

The package includes `comfy-aliases.inactive.json` with the direct and AIO
translation data. The host does not expose this file as an alias registry, so
installing the provider cannot publish mappings through the core image pack.

Preprocessing, relative-depth normalization, and output sizing match
comfyui_controlnet_aux commit
`59b1fc411ede8623b2997855b8018f0b3b6cf49f`. The parity vector in
`tests/goldens/depth_anything_v2_controlnet_aux_59b1fc4.json` is generated by
`tools/gen_depth_anything_v2_golden.py`, which refuses a modified reference
checkout or a reference HEAD other than that commit.
