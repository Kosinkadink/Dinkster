# dinkster-vision-depth-anything-v3

`dinkster-vision-depth-anything-v3` is the separately installable Depth Anything
3 Mono Large provider for `dinkster.preprocess.model_depth`. It runs in an
isolated CPU pack worker and uses the digest-pinned Apache-2.0 checkpoint
declared in `dinkster-pack.toml`.

The checkpoint is read only through `dinkster_api.v1.declared_asset`; execution
never downloads it. Dinkster preflight presents the exact artifact need and
acquires it only with user consent. The pinned 1,336,748,056-byte artifact has
SHA-256 `9b44eda5bedba5b4e125686fdb79d1db309c1b9785277576eb930f885b008f96`.
Its BLAKE3 digest is
`c7c3ae1883d3ad41d64aa9ce2988f265fa3c437105fadc32ff2949b7e8f18323`.

Each frame is resized so its longest edge is 504 pixels, with dimensions
rounded to multiples of 14, and normalized on the same 8-bit ImageNet grid as
ComfyUI. The direct depth prediction is resized to the source dimensions,
normalized with near values white, and then sized according to the stable
model-depth node's `resolution` input.

Architecture, preprocessing, and output conversion match ComfyUI commit
`e7051b03758a1247e3adb84a5b784ffacb9a23bd`. The parity vector in
`tests/goldens/depth_anything_3_mono_large_e7051b0.json` is generated by
`tools/gen_depth_anything_v3_golden.py`, which refuses a modified reference
checkout or a reference HEAD other than that commit. Exact vector parity uses
one torch intra-op thread and has golden SHA-256
`9b5b498adcfc82083f977542d614cabfe85ec6cbb399b04f47a43170bbcf5b00`;
ordinary provider execution retains the worker process's thread settings.
