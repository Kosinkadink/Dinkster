# dinkster-vision-efficient-sam

`dinkster-vision-efficient-sam` is the separately installable EfficientSAM-Ti
execution provider for `dinkster.detection.segment`. It runs in an isolated pack
worker on CPU and uses each detection's region as a box prompt. The output
preserves detection order, labels, scores, and regions while attaching one
full-frame soft mask to each detection.

The provider accepts exactly one image frame because detections do not carry a
batch index. Empty or fully out-of-frame regions produce zero masks. For valid
regions, the EfficientSAM decoder's highest predicted-IoU candidate is selected
and its logits are converted to float32 mask probabilities.

The Apache-2.0 EfficientSAM implementation and ONNX exports are pinned to
commit `d525f622e6f640acf5a0fc37c7ca1f243da5bde0`. The declared encoder and
decoder total 41,365,489 bytes and are read only through
`dinkster_api.v1.declared_asset`; execution never downloads them. The pack pins
ONNX Runtime 1.29.0 and NumPy 2.5.1.

The parity vector in `tests/goldens/efficient_sam_vitt_d525f62.json` is
generated by `tools/gen_efficient_sam_golden.py`, which refuses a modified
reference checkout or a reference HEAD other than the pinned commit. Generation
uses sequential CPU execution with one ONNX Runtime intra-op thread on an AMD
AVX2 host without AVX-512. Ordinary provider execution retains ONNX Runtime's
optimized CPU thread settings.
