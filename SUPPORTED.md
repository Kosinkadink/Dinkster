# Dinkster - Supported Capabilities

What Dinkster supports today, for humans. A capability listed here works
end-to-end through `dinkster-serve` unless it is in the final "Implemented
capabilities with limited or specialized exposure" section. Anything not
listed is not supported. How things work lives in the code and each package's
README, not here. Update the matching area document in the same commit that
changes what is supported.
