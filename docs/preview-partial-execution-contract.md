# Preview and partial-execution conformance v1

`tests/goldens/preview_partial_execution.json` is the canonical backend
semantic-case contract. Its `formatVersion` is 1 and its five stable cases
are generated by `scripts/generate_preview_partial_execution_golden.py` by
constructing native `Graph`/`GraphNode`/`Link` values and calling the real
`Engine.run`. The graph digest hashes sorted canonical native graph wire.
Each case names nonempty top-level node targets, post-run inspection
selections, executed/cached/skipped sets, terminal state, descriptors,
values/renditions where applicable, and causal event constraints. It does
not pin a complete progress transcript because runtime chatter may be
coalesced or dropped.

Targets are node ids only. `(nodeId, outputId)` selects an already-produced
value after execution and never participates in planning, pruning, cache
identity, fingerprint lookup, or stale/valid prediction. Region iteration
paths are likewise observation-only. Structural validation, cycle checks,
and missing-asset preflight remain graph-wide.

## Preview-marked final outputs

Schema wire 16 may carry `preview: true` on an ordinary output entry or an
output-family declaration. Omission and `false` decode to false; every other
JSON type is malformed. Encoders omit false. Wire 15 neither emits nor
interprets the field. An output-family marker propagates to every elaborated
ordinary member. The marker is final-output discovery metadata only and is
recursively removed from computation signatures. It never selects targets,
schedules output-level work, changes a cache key, chooses a renderer, or
grants value access.

There are two separate preview channels. `report_preview` emits ordered,
ephemeral, droppable runtime frames with run and node provenance before a
node terminal event. A preview-marked `OutputSpec`, including one elaborated
from a preview-marked `OutputFamilySpec`, identifies an ordinary final value
after successful execution; its descriptor, retrieval, renditions,
authorization, retention, and eviction use the existing value surface.
Neither channel is a fallback or storage mechanism for the other.

Raw cache inspection requires a separate provenance/freshness/auth/eviction
design. Rich preview descriptions require a future reviewed wire contract.
Region-interior targets require stable planner identities.

## Schema catalog

The schema catalog carries preview and lazy fields. Production catalogs exclude
the `dev.conformance.*` proof nodes. No service, route, event, cache-peek,
renderer-dispatch, HTML/CSS/URL, or durable runtime-preview surface is part of
this contract.
